# Render is retired

The API no longer deploys to Render. There is no `render.yaml`, and there is no paid Render plan.

Deploy Cloud Run and Firebase Hosting with [DEPLOY_CLOUD_RUN.md](DEPLOY_CLOUD_RUN.md).

If a Render service named `ace-digital-api` still exists, delete it in the Render dashboard so a leftover free or paid instance is not serving traffic.
